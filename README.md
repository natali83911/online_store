# Название проекта
Online Store на Django

# Описание проекта
Проект представляет собой интернет-магазин, разработанный с использованием Django и Python 3.12.
Цель проекта — продемонстрировать организацию веб-приложения с использованием современного стека, включая маршрутизацию, работу с моделями, миграции, обработку форм и базовую структуру.

## Основные особенности
* Использование Django 5.2

* Стандартная архитектура проекта с отдельным приложением catalog для разделения функционала

* Реализованы страницы “Главная” и “Контакты” с использованием маршрутов и шаблонов Django

* Безопасность формы с CSRF-защитой

* Поддержка миграций моделей

* Использование именованных маршрутов для упрощения навигации

* Структура проекта
~~~
online_store/
├── manage.py                 # Административная утилита Django
├── src/
│   ├── config/
│   │   ├── settings.py       # Основные настройки проекта
│   │   ├── urls.py           # Главный роутер проекта
│   │   └── wsgi.py
│   ├── catalog/
│   │   ├── urls.py           # Роуты приложения catalog (“home”, “contacts”)
│   │   ├── views.py          # Представления приложения
│   │   └── migrations/       # Миграции базы данных
├── static/                   # Папка для статических файлов (создать, если отсутствует)
├── templates/                # Общие шаблоны проекта
└── pyproject.toml            # Конфигурация Poetry и зависимости
~~~

# Установка и запуск

* Клонировать репозиторий:
~~~
git clone https://github.com/natali83911/online_store.git
cd online_store
~~~

* Запустить виртуальное окружение и установить зависимости:
~~~
poetry shell
poetry install
~~~

* Запустить локальный сервер разработки:
~~~
python manage.py runserver
~~~

* Открыть в браузере:
http://127.0.0.1:8000/
