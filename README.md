# Название проекта
Online Store на Django

# Описание проекта
Проект представляет собой интернет-магазин, разработанный с использованием Django и Python 3.12.
Цель проекта — продемонстрировать организацию веб-приложения с использованием современного стека, включая маршрутизацию, работу с моделями, миграции, обработку форм и базовую структуру.

## Основные особенности
* Использование Django 5.2

* Стандартная архитектура проекта с отдельным приложением catalog для разделения функционала

* Реализованы страницы “Главная” и “Контакты” с использованием маршрутов и шаблонов Django

* Безопасность формы с CSRF-защитой

* Поддержка миграций моделей

* Использование именованных маршрутов для упрощения навигации

# Установка и запуск

* Клонировать репозиторий:
~~~
git clone https://github.com/natali83911/online_store.git
cd online_store
~~~

* Запустить виртуальное окружение и установить зависимости:
~~~
poetry shell
poetry install
poetry add Pillow
~~~

* Создать и применить миграции базы данных:
~~~
python manage.py makemigrations
python manage.py migrate
~~~
Если вы используете фикстуры или у вас есть кастомная команда для наполнения БД тестовыми данными,
загрузите их на этом шаге (по необходимости):
~~~
python manage.py loaddata category_fixture.json
python manage.py loaddata product_fixture.json
~~~
или 
~~~
python manage.py populate_products
~~~

* Создать суперпользователя для доступа к админке:
~~~
python manage.py createsuperuser
~~~

* Запустить локальный сервер разработки:
~~~
python manage.py runserver
~~~

## Особенности работы с проектом
- В проекте реализованы страницы Главная (home) и Контакты с использованием Django-маршрутов и шаблонов.
- Используются именованные маршруты для удобной навигации.
- Поддерживается загрузка и отображение изображений продуктов.
- В модели Product и Category реализованы поля для удобного управления данными и их отображения в админке.
- В проекте настроена CSRF-защита для форм.
- Статические файлы рекомендуется хранить в каталоге static/ в корне проекта.
- Для наполнения базы тестовыми категориями и продуктами можно использовать кастомную management команду (populate_products) или фикстуры.
- Для разработки используется встроенный сервер Django, который не предназначен для продакшен-среды.
